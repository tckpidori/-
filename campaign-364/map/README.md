# Карта 365 года

`map365.html` — карта (нужна только d3 с CDN). Слои: «Политическая» и «Контроль игроков».

Уровни:
- **Империя / раздел** — Западная и Восточная Римские империи, Великая Армения, Персия, Кавказ, Варварская Германия и т. д.
- **Диоцез** (у Рима) или область — 24.
- **Провинция** — 183, по списку `../regions.md`. Контроль игроков задаётся на уровне провинции.
- **Малая провинция** — 1305 клеток примерно равного размера на основе графств CK3. Мелкие графства слиты с соседом, крупные разрезаны. Название: античное имя местности (`pipeline/names.py`, `pipeline/names3.py`) и римская цифра, если в местности несколько клеток.
- **Город** — 284, уменьшенная или увеличенная копия баронства CK3; размер по рангу города (4 ступени).

Основа — провинции Crusader Kings III (открытый мод The Kingdom of Heaven, GitHub `LeSingeAffame/The-Kingdom-of-Heaven`).

Сборка (`pipeline/`): `world.py` (вся модель: диоцезы, провинции, города, игроки) → `build1.py` (суша и стены в реальных координатах) → `regras3.py` (растр провинций) → `geo.py`, `titles.py` (привязка CK3 к координатам, титулы) → `assign3.py` (графства по провинциям, города по баронствам) → `build3.py` (провинции, малые провинции, города) → `export3.py` + `page3.html`. Утилиты на C: `grow.c`, `grow2.c`, `label.c`.
