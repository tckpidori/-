# Карта 365 года

`map.html` — страница карты (нужна только d3 с CDN).

Провинции сняты с эталонной карты `pipeline/ref.jpg`. Области — 63 из `pipeline/regions63.py`, 90 городов там же.

Сборка (`pipeline/`):
1. `seg.py` — провинции, пустошь и вода из картинки (увеличение ×3).
2. `tps.py` — привязка картинки к координатам по ориентирам (сплайн).
3. `build1.py`, `build2.py` — растр 63 областей по римским провинциям (данные AWMC и Natural Earth).
4. `build.py` — реки, раскладка провинций по областям, лёгкое укрупнение, города-участки.
5. `export.py` + `vec.py` — векторизация и данные для страницы, `page.html` — шаблон.
