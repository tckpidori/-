# Карта 365 года

`map365.html` — карта (нужна только d3 с CDN). Слои: «Политическая» и «Контроль регионов».

Три уровня:
- **Регион** — как на карте Траяна (Лугдунская Галлия, Италия, Азия…). Регионом владеет игрок. Всего 60.
- **Провинция** — пункты списка `../regions.md`; там, где регион совпадал с одним пунктом, он разделён на настоящие позднеримские провинции (Lugdunensis Prima/Secunda/Tertia/Senonia и т. п.). Всего 163.
- **Город** — малая провинция внутри своей провинции: уменьшенная или увеличенная копия баронства CK3, размер по рангу города (4 ступени). Всего 90.

Основа — провинции Crusader Kings III (открытый мод The Kingdom of Heaven, GitHub `LeSingeAffame/The-Kingdom-of-Heaven`).

Сборка (`pipeline/`): `build1.py` → `regras.py` (растр пунктов списка в реальных координатах) → `geo.py` (привязка CK3 к координатам) → `titles.py` → `assign.py` (графства CK3 по пунктам списка, города по баронствам) → `build2.py` (провинции и города; модель в `model.py`) → `export2.py` + `page2.html`. Утилиты на C: `grow.c`, `grow2.c`, `label.c`.
