# Карта 365 года

`map365.html` — карта (нужна только d3 с CDN). Слои: «Политическая» и «Контроль игроков».

Основа — провинции Crusader Kings III (карта из открытого мода The Kingdom of Heaven, GitHub `LeSingeAffame/The-Kingdom-of-Heaven`).
- Город: баронство CK3, в котором стоит город (как Константинополь в CK3).
- Провинция: графства CK3, сгруппированные по герцогствам внутри области, 1–9 на область.
- Область: 63 области из `../regions.md` плюс восточные области по карте Траяна и соседи (`pipeline/regions_all.py`).

Сборка (`pipeline/`): `build1.py` (суша и стены в реальных координатах) → `regras.py` (растр областей) → `geo.py` (привязка CK3 к координатам по баронствам с реальными названиями) → `titles.py` → `assign.py` (графства по областям, города по баронствам) → `build.py` (провинции) → `export.py` + `page.html`. Утилиты на C: `grow.c`, `grow2.c`, `label.c`.
