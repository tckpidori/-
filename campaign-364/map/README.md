# Карта 365 года

`map-365.html` — самодостаточная страница (нужна только библиотека d3 с CDN). Опубликована как артефакт.

`regions.json` — таблица областей: область, город (рус./лат.), координаты, фракция, ранг подписи.
Строки с фракцией `X` — служебные точки, ограничивающие области вне игры (пустыни, леса, степь).

## Как собирается

Исходные данные (не в репозитории, тянутся из GitHub):
- Natural Earth 50m (`nvkelso/natural-earth-vector`): берега, озёра, реки.
- Ancient World Mapping Center (`AWMC/geodata`): внутренние границы провинций после Диоклетиана и внешняя граница империи 200 г.

Пайплайн в `pipeline/`:
1. `prep.py` — обрезает и упрощает берега, озёра и крупные реки → `geo.js`.
2. `prep2.py` — растр 0,02°: земля, «стены» (границы провинций, граница империи, Рейн, Дунай, Днестр, Дон, вал Адриана),
   связные компоненты (`label.c`), привязка каждой клетки к городу из `regions.json` → `lab.npy`, `raster.png`.
3. `prep3.py` — векторизация растра в общие дуги (как TopoJSON) и кольца областей → `topo.js`.
4. `page.html` + подстановка `topo.js`, `geo.js`, `regions.json` → `map-365.html`.
